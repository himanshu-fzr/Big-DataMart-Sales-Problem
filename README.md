📌 Project Overview

This project focuses on solving the Big DataMart Sales Prediction Problem using Python and Machine Learning techniques.
The main objective is to analyze sales data, clean and preprocess the dataset, perform Exploratory Data Analysis (EDA), and build predictive models to estimate product outlet sales.

The project includes:

- Data Cleaning & Preprocessing
- Feature Engineering
- Exploratory Data Analysis (EDA)
- Data Visualization
- Machine Learning Model Building
- Sales Prediction

Key Insights:
- Products with higher MRP tend to generate higher sales.
- Supermarket outlets contribute more sales compared to grocery stores.
- Outlet establishment year impacts overall sales performance.
- Certain item categories show consistently high demand.
